## 로컬 구현

src/lib/referrals/ledger.ts는 이벤트에서 상태를 재구성하는 계산 모듈입니다. 운영 API에서 호출하지 않습니다.
계약금 수동 확인, 코드 유지, 추천 관계, 소개 건별 혜택, 잔금 적용, 부분 지급, 지급 정정, 취소·회수 면제 기록의 기초 처리를 포함합니다.
지급 완료 기록은 실제 송금을 수행하지 않습니다.

아직 서버 인증·입력 스키마 검증, 영구 저장·동시 요청 잠금, 공개 조회 요청 제한, 안전한 서버 코드 생성, 관리자 UI, 고객 입력 연결, 단계별 발송 재시도, 이전 미리보기는 연결하지 않았습니다.
입금 확인 후 추천 관계 변경은 현재 초안에서 차단되며, 사유·변경 전후·정산 정정 처리를 구현해야 합니다.
코드 소유 고객 자신의 계약 취소 시 이후 혜택 처리 정책은 운영자 확인이 필요합니다.

## 백업과 롤백

로컬 /workspace/work/referral-backup/repository-before.bundle에 기존 저장소의 Git 기록을 보관했습니다.
같은 디렉터리의 drive-source-20261102.gs는 Drive 적용소스 사본입니다. 실제 운영 배포 및 데이터 백업으로 간주하지 않습니다.
현재 변경은 feature/lifetime-referrals 로컬 브랜치에만 있습니다. 운영 롤백은 필요하지 않습니다.
운영 반영 전 실제 Apps Script 배포 ID·버전·전체 코드·연결 시트 구조와 데이터 사본, Vercel 배포 ID·커밋을 기록해야 합니다.
롤백은 이전 코드 배포 복원으로 수행하며, 이미 발생한 정산 이력은 삭제하지 않고 정정 이벤트로 처리해야 합니다.
